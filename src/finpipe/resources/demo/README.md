# 真实离线演示来源

`manifest.json` 是 2026-10-13 实际采集的冻结清单，`capture_kind=real`，不是人工夹具。公司为 `600519.SH`、`000333.SZ`、`000651.SZ`，期间为 2024Q1–2025Q4，三类完整报表共有 72 个业务键。

每个公司、报表请求使用 `page_size=2`，实际读取 4 页；36 页全部通过分页、字段存在性和身份验证。`raw/` 保存 HTTP 响应正文的字节摘要与原文。重放检查 SHA256 并重新解析正文，清单中的 `rows` 仅用于人工浏览，不能替代原文校验。重放保留每页真实 `observed_at`，不将运行当下时间冒充首次观察。

`universe/universe.json` 是同日实际读取的 2025 年报 A 股列表与冻结 50 家样本。来源行业字段为 `BOARD_NAME/BOARD_CODE`；机构类型和上市日期在该列表中未提供，不根据公司名称、代码或当前分类推断历史披露资格。名单分类页原文保存在 `universe/raw/`。

这批来源是采集当时可见的财报版本。公告、来源更新和本系统观察时间分别记录，不能凭当前快照声称获得了历史真实 PIT。来源、处理流程及边界见[题目回应](../../../../题目回应/README.md)。
