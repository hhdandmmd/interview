# 岗位 JD（用户提供）

记录日期：2026-10-13。用于项目方案评审与交付取舍，来源为用户粘贴的岗位描述。项目范围仍以机试题为主。

## 一、岗位职责

### 1. 数据可信度体系建设（监控与告警）30%

- 设计并实现数据质量监控体系：校验规则、异常检测、告警。
- 覆盖四类风险：上游数据源变更或中断、定时任务失败、数据静默错误、表与字段口径混乱。
- 达到“告警 → 定位 → 重跑”闭环：告警带上下文（哪张表、哪一批、影响哪些下游），能定位问题并重跑恢复。
- 监控指标可量化：行数突变、空值率、覆盖率、字段更新频率等。

### 2. 数据生产流程开发与优化 25%

- 量化数据的采集、清洗、转换、入库流程开发。
- 数据同步工具开发（数据库同步、文件同步）。
- 定时数据任务调度与维护。
- 数据流水线优化与性能调优。
- 数据缺失与异常的排查与修复。

### 3. 基础数据与数据字典 20%

- 股票基础数据管理（日频/分钟线 K 线、指数、成分股、财务数据等）。
- 期货数据管理（行情、主力合约映射、合约信息、新品种上线）。
- 可转债、期权等衍生品种数据管理。
- 数据字典维护与使用说明更新。
- 处理结构较复杂的数据（公告、财务、估值表等）。

### 4. 数据生成与维护 15%

- 衍生字段与元数据：复权因子、涨跌停价、停牌标记、行业分类、交易日历等。
- 指数生成与维护、全市场对齐宽表/面板数据。
- 时点口径数据（PIT / 版本追溯）。

### 5. 数据源接入与变更响应 10%

- 数据供应源的数据接入与日常维护。
- 上游字段变更、服务中断的响应与兼容处理。

## 二、任职要求

1. 国内外优秀院校计算机/数据科学相关专业，本科及以上。
2. 应届至 3 年，有数据处理项目经验即可。
3. Python（工程与数据），有 C++、C#、Rust、Go、Java 等经验更佳。
4. 精通 Pandas/NumPy，有采集、清洗、转换、入库完整流程开发经验。
5. 熟悉列式存储（Parquet 等）与分区设计，理解文件数、分区粒度对读写性能的影响。
6. 精通主流关系型数据库，有复杂查询和性能调优经验。
7. 能定义数据正确性，实践过行数、空值率、覆盖率、更新频率等校验。
8. 生成过复权因子、涨跌停价、停牌标记、行业分类、指数、宽表等衍生数据。
9. 对维护的数据有整体认知：量级、日增量、耗时、下游使用方、改动影响面。
10. 熟练使用 AI 编程工具，能高效利用 AI 完成开发任务。
11. 对口径与正确性有高标准，同时保证编码、排障和任务交付效率。
12. 配合度高，有工程化思维、自动化意识、闭环推进、文档沉淀；愿意自学、接受新事物，能在模糊需求下主动澄清并推进。

## 三、加分项

- 量化数据平台经验。
- 熟悉 PyArrow/Dask。
- PIT / 版本追溯经验。
- 数据质量监控体系建设经验。
- 股票、期货、可转债等金融数据认知。
- 数据治理经验。

## 本轮用户补充的交付标准

项目应在机试要求基础上尽量完整，像真实可交付项目；强调工程化、可维护、可扩展，避免把不同职责都塞进一个文件，同时检查设计是否臃肿。当前任务为多个专职 agent 的独立方案评审及统一修订。
