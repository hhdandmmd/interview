# 当前财务数据口径

本文对应实际实现，不把公开修订财报当作完整历史PIT。字段和公式以发布快照的生成字典为准，维护入口见[架构](architecture.md)与[字典说明](data_dictionary.md)。

## 范围、原文与时间

处理自然年季度、人民币、非金融A股公司合并利润表、资产负债表和主要指标。默认冻结沪深京50家公司，输入2022Q1—2025Q4，输出2023Q1—2025Q4；多一年用于同比和单季计算。固定名单不能证明历史上市退市或无生存偏差。

HTTP响应先保存原字节、请求、观察时间和SHA，再解析。来源内容、真实观察和重放分别记账，重放保留捕获时间。人工夹具显式标记并使用独立工作区。

代码保留六位数字和交易所，报告期只允许季末。金额统一为人民币元，百分数转小数，流比保持倍数。缺失、非法和数学无定义输出NULL及原因，不填零或前向填充。

公告/已知更新边界、真实观察、处理和实际发布分别保存。来源只有日期时按上海下一日零点保守放出；早于报告期、晚于观察或无可信精度时隔离或保留无效时间状态。精确观察/处理时间不能由日期伪造。

特征可用时间取精确输入的实际可用上界，消费还须满足发布边界。query --as-of选择当时已发布快照。公告近似研究走独立publication_proxy入口，保留真实时间且说明历史版本未核验，见[回测](backtest.md)。

## 版本与计算

真实来源采用最新完整观察确定当前内容；重复内容复用源版本，新观察仍保留。同一扫描多个不同版本形成冲突，旧归档不覆盖较新事实，UPDATE_DATE不冒充官方修订序列。

先选最新来源状态再判断可计算性。坏新版、冲突或缺失使相关依赖产生NULL，不能过滤坏版本后找旧好值。旧值和快照保留用于审计，规则改变生成新profile。

| 计算 | 实际边界 |
| --- | --- |
| 单季流量 | Q1取累计；Q2—Q4减同年准确上一季度，缺季度不跨行差分 |
| 同比/环比 | 准确lag4/lag1关联，Q1环比在上一年Q4 |
| 净利率 | 合并净利润/营业收入，累计和单季分别输出 |
| 毛利率 | （营业收入－营业成本）/营业收入，不混用营业总收入 |
| 利润成长 | 归母净利润，正基期才算相对增长，亏损不伪装正常增速 |
| ROE | 披露累计加权ROE转小数，相对变化和百分点差分开 |
| 偿债 | 期末存量，流比保持倍数，变化按准确期间计算 |

累计差分及跨期变化需要可比基础。已知重述风险而没有可比历史输入时停止相关计算；没有已知风险但缺独立核验时可按source_assumed警告计算，不声称已验证重述。单期值和同期比率独立判断。

## 质量与发布

覆盖以请求全集为分母，缺报表不自动剔除为不适用。字段、记录、因子和全范围门禁分别处理，保留空值/异常、基线、恒等式与比率核对及问题上下文。

同源勾稽只证明内部一致性。官方原报告核对须一致的公司、期间、合并范围、单位、版本及精度，未覆盖、不可比和不匹配另列，见[独立核对](original_report_validation.md)。

候选通过质量、全集、血缘及文件摘要校验才发布。SQLite为唯一发布权威，PREPARED或只有目录不能消费，旧候选不覆盖新head。派生回执可修复，原文与封存产物不覆盖。
