## 复核方式与边界

[核对脚本](../data/reference/original_reports/verify_reference.py)只处理这五份固定报告，人工指定字段、当年合并列和参考值。它检查 PDF 及来源正文 SHA256、原值是否实际出现在指定页，用 Decimal 直接读取来源 HTTP 数字比较，不调用业务清洗或因子函数。`pypdf` 为一次性研究工具，仅安装在项目 `.venv`，没有加入运行依赖。参考 JSON 生成时拒绝覆盖已有输出。

```powershell
# 如需在新环境重跑这项研究验证，单独安装一次性工具；日常流水线不需要。
.\.venv\Scripts\python.exe -m pip install pypdf==6.20.1 --index-url https://pypi.org/simple

# 重新读取既存证据并核对，只打印结果，不改原文或参考记录。
.\.venv\Scripts\python.exe data\reference\original_reports\verify_reference.py
```

本次针对演示数据中的 `600519.SH` 和 `000333.SZ`，两家公司不在当前按代码分层选择的默认 50 家名单中。正式核对须使用包含这两家、这些期间的演示工作区；在另一范围执行，应显示未覆盖或范围不匹配，不能自动算成功。未对默认 50 家逐一进行原报告核验，未自动修改任何公司的版本裁决或验证状态。

PDF 文本由本地已保存原文抽取；网页截图工具本次不可用，因此没有声称完成截图视觉验收。必要字段摘录、页码和原 PDF 已保留，评审者可以直接打开原文复核。原捕获正文、冻结来源清单、PDF 和下载清单均未覆盖。
