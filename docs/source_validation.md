# 数据源实测记录

验证日期：2026-10-13（上海时区）。本次验证访问公开接口，不需要账号或 API Key；解析后保存的源 JSON 与请求 URL 保存在项目目录，所有结果均来自实际请求。这些证据不是原始 HTTP 字节归档；字段值保留不等于正文的字节、格式和摘要被保留。

## 1. 当前验证范围

3 家非金融公司：贵州茅台 `600519.SH`、美的集团 `000333.SZ`、格力电器 `000651.SZ`，报告期为 2024-12-31。

每家公司验证完整利润表、完整资产负债表、主要财务指标，共 9 项；另外对茅台验证利润汇总、资产负债汇总、业绩列表，共 3 项。**12 项均成功返回预期业务身份与必需字段，最终探测进程退出码为 0。**

结果见[接口验证记录](../data/evidence/source_probe.json)。其中 `at_utc` 是该次请求开始时间，`observed_at_utc` 是该次响应解析完成时间，后者才可作为这份快照的实际观察时间依据。重试记录也一并保留。本轮评审和离线回归没有覆盖这些真实证据文件。

这是字段与数据源可行性验证，尚未执行 50 家、多报告期分页采集，也未验证全部接口的长期稳定性；独立原始年报核对在实现验收阶段完成。

源栏目：[年报季报](https://data.eastmoney.com/bbsj/)、[利润表](https://data.eastmoney.com/bbsj/lrb.html)、[资产负债表](https://data.eastmoney.com/bbsj/zcfz.html)。公开个股页面还区分[首次公告与最新公告日期](https://data.eastmoney.com/bbsj/000070.html)，设计因此保留多种时间证据。

## 2. 决定架构的实测差异

### 报告日期字段不同

完整财报用 `REPORT_DATE`，业绩列表 `RPT_LICO_FN_CPD` 用 `REPORTDATE`。字段和查询过滤器必须按报表配置，不能写成一个全接口共用的硬编码名称。

实测过滤器中，日期使用单引号，证券代码使用双引号，例如：

```text
(REPORT_DATE='2024-12-31')(SECUCODE="600519.SH")
```

证券代码使用单引号时，本次接口返回参数预处理错误。验证工具使用 `urlencode` 编码完整查询参数，避免手拼 URL 转义。

### 完整报表与汇总表并不等价

贵州茅台完整利润表返回 `OPERATE_INCOME=170899152276.34`，但利润汇总表的同名字段为 null；汇总表的营业总收入是 `174144069958.25`。两者不能静默互换。

完整利润表也提供 `NETPROFIT` 与 `PARENT_NETPROFIT`，使合并净利率与归母利润成长能分别计算。因此主采集使用完整报表，避免靠汇总值拼凑不同财务口径。

### 比率单位不同

贵州茅台完整财务指标的 `LD=4.454078781594`，汇总资产负债表的 `CURRENT_RATIO=445.4078781594`；名称相近的字段相差 100 倍。

以完整资产负债表的流动资产 `251726674636.66` 除以流动负债 `56515990618.96`，得到 4.454078781594 倍，与 `LD` 一致。首版明确采用完整表金额自行计算，源端指标用于核对。

### 公告日期与更新时间不能混用

茅台 2024 年报的完整表返回：

```text
REPORT_DATE = 2024-12-31
NOTICE_DATE = 2025-04-03
UPDATE_DATE = 2026-04-17
```

利润汇总表的 `NOTICE_DATE` 却返回 2026-04-17。实测只能证明源接口返回了这些日期，无法仅据此判定 2026-04-17 是正式财报更正日，还是数据商刷新日期。

所以源公告、源更新、系统观察时间分开保存。当前响应中的旧年数据也不能被自动视为 2025 年当时已知的原始财报值。

## 3. 数值交叉核对

核对使用完整表金额独立运算，再比较指标表。这是同源一致性检查，不代替企业正式年报核验。

| 公司 | 累计毛利率 | 累计净利率 | 流动比率 | 源披露加权 ROE |
| --- | --- | --- | --- | --- |
| 贵州茅台 | 91.9312% | 52.2734% | 4.454079 倍 | 36.02% |
| 美的集团 | 26.4190% | 9.5192% | 1.105861 倍 | 21.29% |
| 格力电器 | 29.4282% | 17.1127% | 1.117725 倍 | 25.42% |

毛利率采用 `1 - OPERATE_COST / OPERATE_INCOME`，净利率采用 `NETPROFIT / OPERATE_INCOME`，流动比率采用 `TOTAL_CURRENT_ASSETS / TOTAL_CURRENT_LIAB`。具体小数数值见保存的 JSON；探测脚本按标准 JSON 数值解析，不能据此宣称字节级精度归档。

三家公司这三项计算与源指标转换后的绝对误差均小于 `1e-10`。资产减负债减权益的差额也在 1 元以内；格力存在约 `-0.0000305` 元的浮点误差，因此会计恒等式校验使用明确容差，不直接比较浮点数是否严格相等。

## 4. 银行诊断

平安银行 `000001.SZ` 的完整利润与指标接口可返回数据，其中 `ORG_TYPE=银行`、`OPERATE_COST=null`、`XSMLL=null`、`LD=null`。通用资产负债报表 `RPT_F10_FINANCE_GBALANCE` 连续两次返回业务层“返回数据为空”，未将它解释为正常的零资产。

进一步实测银行报表 `RPT_F10_FINANCE_BBALANCE` 返回总资产、总负债，说明该来源的银行资产负债表使用不同报表名。本项目第一版范围仍为非金融企业；后续支持银行需单独声明字段契约和适用因子。

诊断响应见[银行通用接口记录](../data/evidence/bank_probe.json)与[银行专用资产负债表记录](../data/evidence/bank_balance_probe.json)。早期通用接口记录的 `at_utc` 仅为请求开始时间，不可当作严格时点研究的快照观察时间。

## 5. 复现命令

验证工具仅使用 Python 标准库。每次请求前至少等待 1 秒，瞬态网络故障及 HTTP 408/429/500/502/503/504 最多尝试 3 次，保留实际错误。403 等非瞬态 HTTP 错误不重试；响应结构和业务参数错误不重试。尊重 Retry-After 秒数或 HTTP 日期，等待超过 30 秒时输出 retry_deferred 与 next_retry_at；本次同源剩余报告/公司记录为 not_attempted，不提前向同源发请求。

```powershell
# 默认三家非金融公司，额外比较第一个公司的汇总接口
python scripts/probe_source.py --summaries --output data/evidence/new_probe.json

# 指定公司、报告期、证据输出文件
python scripts/probe_source.py --codes 600519.SH --period 2024-12-31 --output data/evidence/custom_probe.json

# 银行专用资产负债表，仅检查其适用字段
python scripts/probe_source.py --codes 000001.SZ --report RPT_F10_FINANCE_BBALANCE --output data/evidence/new_bank_balance_probe.json
```

命令会重写指定证据文件，若需要保留一次采集的历史，请更换输出文件名。真实业务流水线将使用不可变运行目录，不用这个验证脚本的覆盖写入方式。

## 6. 本轮实际修复与回归

测试评审以 mock 注入错误，确认评审前脚本存在非瞬态 HTTP 重试、忽略 Retry-After、金额类型/披露日期及额外返回行校验不足。最后工程复核还发现精确公告时间降成日期后，会接受同日未来公告；主负责人补查同源剩余请求的长限流传播。修复后加入[离线回归](../tests/test_probe_source.py)，用标准库 unittest 执行 29 项测试，涵盖上述缺陷、NULL 金融字段、时区、返回 count/pages、临时目录 CLI 和现有 12 项响应复验。

```powershell
python -B -m unittest discover -s tests -p test_probe_source.py -v
```

这些测试不访问网络，不修改真实证据。当前没有重新执行在线全范围采集，因此不能将脚本修复外推为“公开接口长期稳定”或“50 家多季度流水线已验收”。业务验收见[验收标准](acceptance.md)。
