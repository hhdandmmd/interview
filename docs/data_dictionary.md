# 数据字典的查看与维护

每个财务发布快照已经输出dictionary.json和dictionary.md。字典由字段、特征、质量规格与SQLite实际结构生成并封存，避免另写一套与代码脱节的字段表。

在交付包根目录双击START_HERE.html查看财务结果，再打开同目录的字典。自己运行后使用返回的export_path定位snapshots/<snapshot_id>。解释特征值、原因和准确输入使用explain，命令见[运行说明](implementation.md)。

字典覆盖三类财务字段、15个特征、状态、质量规则、数据集、SQLite表列及关键约束。特征说明含公式、单位和准确季度依赖。

| 字段类型 | 存储及解释 |
| --- | --- |
| 证券代码 | 字符串，保留前导零和交易所，如000333.SZ |
| 报告期 | 自然年季末ISO日期，不是公告日期 |
| 金额 | 人民币元，不能把万元/千元当作元 |
| 比率 | 小数，0.15表示15% |
| 百分点变化 | 小数差，0.02表示增加2个百分点 |
| 流动比率及变化 | 倍数或倍数差，不乘100 |
| 时间 | 带时区UTC，日期精度按保守边界处理 |
| NULL | 有原因的未知、失效或数学无定义，不等于0 |

源原值保留在HTTP正文与来源版本中。字段状态、记录状态和特征状态承担不同职责，一字段缺失不自动使其他合法值失效，见[数据口径](data_contract.md)。

维护入口：

- catalog.py的FieldSpec维护源字段、单位、期间和存在性。
- features/specifications.py维护特征描述/单位/依赖，calculation.py维护公式。
- quality.py维护规则和指标，可调阈值在配置中随profile冻结。
- resources/migrations与storage/database.py维护物理结构，字典读取实际表列。

财务口径变化要升级规则或公式身份并验证旧版本可追溯；普通说明文字变化不强迫重算。旧设计保留在本地档案，当前交付以生成字典与实际实现为准。
