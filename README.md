# 金融数据处理与特征工程

填写股票和财报季度，运行一次，自动完成 **东方财富财报采集 → 清洗与存储 → 15个财务因子 → 结果报告**。另支持质量检查、增量复用和可选的五组回测。

第一次使用，按下面与你收到的文件对应的一条路径操作即可。无需先读架构或数据库说明。

## 1. 先跑通一次

### 收到包含Windows程序的完整ZIP

1. **先解压整个ZIP**到有写入权限的本地文件夹，不要在压缩软件里直接运行。
2. 在解压后的最外层，双击 **`START_HERE.html`**，点击“查看财务结果”即可先看随包样例。
3. 双击同一目录的 **`run_demo.cmd`**，离线重跑固定样例。无需安装Python，也不需要网络。
4. 等窗口显示“退出码：0”，复制“报告路径”后面的完整路径到浏览器地址栏，打开自己的结果。

离线样例使用茅台、美的、格力的真实HTTP归档，包含72份报表，生成2025年180个因子位置。首次状态为`PUBLISHED`（已生成），再运行通常为`NO_CHANGE`（输入未变，复用结果）；两者都是成功。它使用固定公司，不读取日常`config.py`。

**完整ZIP的操作目录是同时放着`START_HERE.html`、`config.py`、`run.cmd`的最外层。** 日常编辑这里的配置；`source/config.py`供源码开发使用，`config/*.toml`供高级命令使用。

完整ZIP不附开发虚拟环境`.venv`，程序依赖已放在`windows/finpipe`中。直接运行EXE和双击入口均无需创建虚拟环境；题目回应与示例结果位于最外层的`题目回应`文件夹。

### 使用源码或运行自动测试（可选）

GitHub源码包不含Windows程序；完整ZIP的源码在`source`目录。只有选择源码运行或pytest测试时才需要本节。先安装Python 3.13，然后在**含有`main.py`和`requirements.txt`的源码目录**打开PowerShell：在资源管理器地址栏输入`powershell`并回车。

首次安装执行以下两条命令，它们会在当前源码目录创建`.venv`并安装依赖：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

安装成功后，双击根目录 **`run_demo.cmd`**。也可在上述PowerShell中执行：

```powershell
.\run_demo.cmd
```

出现`py`无法识别或找不到3.13时，先安装对应Python再执行；完整Windows ZIP可以免安装。依赖安装需要联网，后续离线演示不需要。项目声明Python 3.11以上，已实测3.12与3.13，3.11尚未实测。

## 2. 换成自己选的公司

离线演示成功后，按以下步骤实际联网采集：

1. 右键同目录的 **`config.py` → 打开方式 → 记事本或代码编辑器**，不要双击执行配置文件。
2. 在已有配置中修改下面三行，保留引号、方括号和行末逗号，保存文件：

```python
    stocks=["600519.SH", "000333.SZ", "000651.SZ"],
    start_period="2025Q1",
    end_period="2025Q4",
```

3. 保留`source="eastmoney"`、`backtest`中的`enabled=False`及其他默认项，双击 **`run.cmd`**。
4. 窗口显示“运行完成”或“已复用结果”，且“退出码：0”后，按“查看报告”的路径打开结果。

这是修改现有配置的片段，不要用这三行替换整个文件。未经修改的默认配置只处理茅台一家，2025年输出60个因子位置；上述三家公司配置对应180个位置。数量包含有原因的空值，不代表全部有数值。

| 配置项 | 怎样填写 |
| --- | --- |
| `stocks` | 证券代码列表：上海`.SH`、深圳`.SZ`、北京`.BJ`；代码保留引号与前导零 |
| `source` | 当前已接入东方财富，填写`"eastmoney"`或`"东方财富"`；其他网站尚未接入 |
| `start_period / end_period` | 要输出的财报季度，例如`"2025Q1"`至`"2025Q4"`；不是交易日期 |
| `output_dir` | 默认保存到配置文件同目录下的`output/financial`，首次使用无需修改 |
| `backtest.enabled` | 默认`False`；先跑通财报，再按[回测说明](docs/backtest.md)启用 |

当前支持人民币、自然年季度的非金融A股。同比和单季计算需要历史，程序会自动补齐上一年财报，不需要手工多填一年。

## 3. 结果在哪里，先看什么

在线自选公司结果在 **`output/financial`**；根目录离线演示结果在 **`output/demo`**。以控制台打印的报告路径为准，无需自己挑选编号目录。

打开`report.html`先看处理摘要，再点击完整因子表。报告所在目录还有：

| 文件 | 什么时候看 |
| --- | --- |
| `features_long.csv` | 查看证券代码、报告期、因子名称、数值、状态和原因；可用Excel打开 |
| `features_panel.csv` | 希望每家公司每季度一行，各个因子展开为列 |
| `income / balance / indicator.csv` | 查看清洗后的利润表、资产负债表、主要指标 |
| `dictionary.md / .json` | 查字段含义、公式和单位；比率`0.1`通常表示10%，流动比率是倍数 |
| `quality.json` | 查看覆盖率、缺失、异常和核对明细 |
| 同名`.parquet` | 用Python继续处理，保留明确的数据类型 |

空值不是零收益或零利润。查看该行的`feature_status`和`reason_codes`；`warning`表示有数值但存在需要关注的口径条件。重复运行会保留来源观察并复用未变结果。

## 4. 遇到问题时

| 现象 | 下一步 |
| --- | --- |
| 双击后提示先安装依赖 | 源码包按第1节安装；完整ZIP应保留整个`windows/finpipe`目录 |
| 改了公司，离线演示仍是三家公司 | `run_demo.cmd`使用固定归档；自选公司请运行`run.cmd` |
| 配置提示语法错误 | 看提示行号，检查英文引号、逗号、括号；不要把完整配置替换成三行片段 |
| 网络超时、证书或403错误 | 保留失败窗口，检查网络或代理；403先确认来源访问限制。需要恢复时复制控制台提供的恢复命令，见[故障处理](docs/windows_usage.md) |
| 找不到生成的HTML | 复制“查看报告”或“报告路径”后的完整路径，不包含前面的中文标签；粘贴到浏览器地址栏 |
| 开回测后提示人数不足或没有窗口 | 五组至少五家公司；财报季度与交易区间不同，默认真实已知时间可能没有历史窗口，见[回测说明](docs/backtest.md) |
| `NO_CHANGE` | 成功复用了已有结果，仍可打开返回的报告 |
| 退出码不是0 | 当前操作未全部成功，按窗口中的原因处理；不要仅凭存在旧报告判断本次成功 |
