# 建议截图清单

截图是可选材料，建议准备以下6张。画面来自真实操作，清晰展示输入、结果和口径即可；已有HTML和CSV可直接打开，不必为截图添加新界面。

## 推荐6张

| 建议文件名 | 截什么 | 怎样操作 | 要保留的内容 |
| --- | --- | --- | --- |
| `01_配置与运行.png` | 公司配置与运行完成的终端 | 打开根`config.py`，运行`main.py`或双击`run.cmd`，把配置编辑器与终端并排 | 股票、来源、财报季度、实际报表/因子数量、完成状态与报告路径；数量按本次配置，不强行写180 |
| `02_财务处理报告.png` | 真实财务HTML首屏 | 打开[财务报告](示例结果/财务处理/report.html) | 数据身份real、质量摘要、证券代码/季度与因子样例 |
| `03_完整因子表.png` | CSV中的正式特征结果 | 用Excel或编辑器打开[features_long.csv](示例结果/财务处理/features_long.csv)，保留核心列，挑选盈利/成长/偿债行 | `security_code`、`report_end`、`feature_name`、`feature_value`、`feature_status`、`storage_unit`；不要把倍数当百分数 |
| `04_质量与清洗.png` | 逐条日志、质量摘要或清洗反例 | 打开[清洗日志](示例结果/财务处理/清洗日志.csv)和[质量JSON](示例结果/财务处理/quality.json)；若展示异常，再打开[人工反例](示例结果/清洗反例.json) | 记录身份、字段状态、NULL/异常原因；人工反例必须露出`data_kind=synthetic`，不能说是真实上游错误 |
| `05_ROE五组回测.png` | 回测说明、净值图与分组结果 | 浏览器打开[回测HTML](示例结果/分组回测/report.html)，可调页面缩放使说明与图同时可见 | 因子名累计加权ROE、G1—G5、日期轴、净值轴、图例、实际持有区间、公告近似/历史版本未核验说明 |
| `06_测试结果.png` | 完整测试最后的结果 | 在源码根目录运行下方pytest命令，或打开[本轮测试文本](测试输出/pytest.txt) | 实际命令、通过数量、子断言与耗时；不只截一个绿色图标 |

## 可选代码截图

推荐`07_因子代码.png`：打开[营收同比factor.py](../src/finpipe/features/factors/revenue_growth_yoy/factor.py)，一屏展示中文说明、`calculate`、公式、依赖和单位。这个文件短，能说明如何添加和维护因子。可另截[字段规格](../src/finpipe/catalog.py)中的一个表，展示字段和单位的集中维护。

无需把数据库25张表或大量旧运行目录截图。面试官更需要看清一条业务链路和一个可以维护的公式。

## 用于截图的命令

在源码根目录执行：

```powershell
# 自选公司在线主线，使用当前config.py。
.\.venv\Scripts\python.exe main.py

# 不依赖公网的真实三公司样例；再次执行可展示复用。
.\.venv\Scripts\python.exe -m finpipe demo --workspace output/截图演示
.\.venv\Scripts\python.exe -m finpipe demo --workspace output/截图演示

# 完整测试，截图终端最后的统计。
.\.venv\Scripts\python.exe -m pytest -q
```

当前根配置默认一家公司，在线结果应与当前配置一致；随附财务HTML则是三家公司离线重放结果。两者分别标注，不混称同一次采集。

可选录制一段2—3分钟演示：展示配置 → 运行完成 → 打开财务报告和因子表 → 查看清洗/质量 → 打开ROE回测图 → 展示测试摘要。网络请求等待可跳过，但说明哪些结果来自离线重放。
