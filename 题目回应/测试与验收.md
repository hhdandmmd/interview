# 测试与验收

这是原题要求的**测试方案**，供审核时选择性复现。第一次使用只需打开交付包最外层的`START_HERE.html`，无需先运行测试。

**完整Windows ZIP不附带开发虚拟环境`.venv`，也不需要它。** 程序和运行依赖已在`windows/finpipe`中；下面先给出解压后即可执行的EXE命令。只有最后一节的源码自动测试需要另行安装Python、创建环境。

## 1. 不安装Python，重跑真实财报

完整解压ZIP，在**同时含有`START_HERE.html`和`windows`文件夹的最外层**打开PowerShell：在资源管理器地址栏输入`powershell`并回车。不要在`题目回应`或`source`目录运行以下命令。

依次执行；上一条退出码为0再继续。首次验收使用尚未创建的`output/面试验收`，已有同名结果时可将五条命令的工作区一起改成`output/面试验收_02`。

```powershell
# 同一真实归档运行两次，检查新增发布与增量复用。
.\windows\finpipe\finpipe.exe demo --workspace output/面试验收
.\windows\finpipe\finpipe.exe demo --workspace output/面试验收
.\windows\finpipe\finpipe.exe query --workspace output/面试验收 --company 600519.SH --period 2025Q4
.\windows\finpipe\finpipe.exe doctor --workspace output/面试验收
.\windows\finpipe\finpipe.exe health --workspace output/面试验收
```

| 操作 | 应看到的结果 |
| --- | --- |
| 第一次demo | `PUBLISHED`；3家公司×8季度×3表=72条来源，输出2025年180个因子位置 |
| 第二次demo | `NO_CHANGE`；新来源、清洗及裁决版本均0，计算0、复用180 |
| query | 仅茅台2025Q4的15个因子，含数值、状态与原因；空值不代表零 |
| doctor、health | 检查通过，退出码0；PowerShell中用`$LASTEXITCODE`查看上一条命令的退出码 |

报告地址取demo结果中的`export_path`，在该目录打开`report.html`。直接双击最外层`run_demo.cmd`也可离线演示，但它固定使用另一个工作区`output/demo`。

已有结果见[示例入口](示例结果/index.html)与[运行验收](示例结果/运行验收.json)；离线重放保留原采集观察时间，不代表本次重新联网采集。

## 2. 复算公开样例的五组回测

仍在**完整ZIP最外层**执行，无需联网或Python。输出目录必须尚不存在；重复运行时将末尾改成`output/面试回测_02`。

```powershell
.\windows\finpipe\finpipe.exe backtest --signals examples/backtest_real/signals.json --market examples/backtest_real/market --time-policy publication_proxy --start 2023-01-01 --end 2025-12-31 --horizon 20 --output output/面试回测_01
```

打开`output/面试回测_01/report.html`。该样例使用十家公司的累计加权ROE，按值从低到高分五组，形成20个有效持有窗口；图有日期轴、净值轴和组别图例。这里明确选择公告时间近似研究，不声称已核验完整历史财报版本。

## 4. 源码自动测试（可选）

仅查看结果、运行EXE或双击入口的人可以跳过本节。需要检查代码时，先安装Python 3.13；首次安装依赖需要联网。

**完整ZIP用户**：在ZIP最外层PowerShell先进入源码目录：

```powershell
Set-Location .\source
```

**GitHub源码用户**：直接在含`requirements.txt`和`main.py`的目录打开PowerShell，跳过上面的进入目录命令。

两种情况均在源码目录依次执行以下命令。第一条会创建此前不存在的`.venv`；第二条安装项目和测试依赖。每条成功后再执行下一条，无需激活环境。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check src tests scripts
```

若提示`py`不存在或找不到3.13，按[源码安装说明](../README.md)安装对应Python。测试通过后也可在该目录运行`.\run_demo.cmd`，由刚创建的环境执行源码。

## 5. 验证边界

- 独立原报告核对为33项匹配、1项不可比、350个左侧字段未覆盖；核对匹配率和覆盖率分别报告。同源勾稽不当作独立核验。
- 五个清洗反例是人工构造的独立案例，不混入真实财务工作区。
- 公开回测采用固定股票池与公告时间近似；完整历史修订、实盘可成交约束与现金分红单独核验尚未完成。
- 提交前会对实际ZIP的文件、链接及运行入口检查；本机移除Python PATH并设置不可用代理的验证，不等同于独立干净Windows机器或操作系统断网。
- Python3.11、生产调度注册、外部通知、整机断电与大规模生产性能未计入验收结论。
