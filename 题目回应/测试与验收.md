# 测试与验收

本方案说明如何核验原题与实际结果。业务数据、人工反例、自动测试和Windows环境检查分开，不把测试计划当作执行记录。

## 先看结果，再重跑

1. 本地浏览器打开[示例入口](示例结果/index.html)，查看财务、质量、清洗、核对与回测。
2. 阅读[逐项题目回应](README.md)，按链接检查代码和结果。
3. 按下面命令在新工作区复现。完整Windows ZIP可直接用程序；源码先按[项目README](../README.md)安装。

当前示例为实际离线重放的真实东方财富归档：3家公司×8季度×3表=72条来源，生成2025年180个因子位置。第二次运行`NO_CHANGE`，新来源/清洗/裁决版本均0，计算0、复用180。实际返回结果与doctor检查见[运行验收](示例结果/运行验收.json)。

独立原报告核对得到33项匹配、1项不可比、350个左侧字段未覆盖；匹配率和覆盖率分别报告。公开ROE回测形成20个持有窗口，实际日期范围见报告。五个清洗反例均为人工构造、直接声明预期状态，独立于真实工作区。

## 原题验收用例

| 维度 | 输入/操作 | 应确认的行为 | 代码测试入口 |
| --- | --- | --- | --- |
| 获取与归档 | 正常三表、多页、429、503、403、缺页或结构变化 | 原字节与观察时间可核验；有限重试、冷却、失败定位；不消费不完整分页 | [test_ingestion.py](../tests/test_ingestion.py) |
| 字段与单位 | 前导零代码、百分数、金额、NULL、坏数字 | 类型/单位明确；非法值与缺失不同；不猜币种或补零 | [test_finance.py](../tests/test_finance.py) |
| 金融公式 | 独立分数手算、缺季度、跨年、亏损、负/零基期 | 单季差分和lag1/lag4准确；无定义保留原因；不得跨缺期按行移位 | [test_finance.py](../tests/test_finance.py)、[test_integration.py](../tests/test_integration.py) |
| 版本与更正 | 相同输入、更正、冲突、新坏版、A→B→A、旧归档 | 重复复用；旧版本可审计；坏新版不能复活旧好值 | [test_integration.py](../tests/test_integration.py)、[test_snapshot_freshness.py](../tests/test_snapshot_freshness.py) |
| 增量等价 | 同一最终输入分别增量与全量、recent刷新、规则变化 | 数值/状态/原因一致；未变部分复用；口径变化必要重算；全集不缩小 | [test_integration.py](../tests/test_integration.py) |
| 质量与恢复 | 覆盖下降、异常字段、心跳超时、健康复发、采集中断与发布中断 | 保守分母；定位批次与下游；旧重放不掩盖在线失效；可按原计划恢复 | [test_quality.py](../tests/test_quality.py)、[test_health_schedule.py](../tests/test_health_schedule.py)、[test_integration.py](../tests/test_integration.py) |
| 查询与存储 | 公司/季度查询、固定快照、CSV/Parquet、文件损坏与备份迁移 | 查询范围正确、类型一致；摘要和SQL约束可校验 | [test_integration.py](../tests/test_integration.py) |
| 回测 | 手算收益、盘后信号、交易日间隔、并列值、缺价与费用 | 五组等权、下一交易日进入、非重叠持有；缺价不删除成员或填零；未知净值停止累计 | [test_backtest.py](../tests/test_backtest.py) |
| 报告与配置 | 因子选择、多因子共用行情、无效参数、空窗口与中文空格路径 | 图有轴/图例/真实范围；失败返回明确状态；配置先校验；保留财报结果 | [test_backtest_report.py](../tests/test_backtest_report.py)、[test_configured_backtest.py](../tests/test_configured_backtest.py)、[test_simple_runner.py](../tests/test_simple_runner.py) |

测试预期包含人工独立分数和Decimal核算，不用待测公式产生全部期望。本轮完整自动回归的实际输出保存在[pytest文本](测试输出/pytest.txt)与[JUnit XML](测试输出/pytest.xml)，环境和统计见[验收记录](测试输出/验收.json)。

## 源码复现命令

在源码根目录执行，无需激活环境：

```powershell
# 重跑真实离线财报，重复执行同一命令检查复用。
.\.venv\Scripts\python.exe -m finpipe demo --workspace output/面试验收
.\.venv\Scripts\python.exe -m finpipe demo --workspace output/面试验收
.\.venv\Scripts\python.exe -m finpipe query --workspace output/面试验收 --company 600519.SH --period 2025Q4
.\.venv\Scripts\python.exe -m finpipe doctor --workspace output/面试验收

# 使用同一公开小样例复算，输出目录需要不存在。
.\.venv\Scripts\python.exe -m finpipe backtest --signals data/examples/backtest_real/signals.json --market data/examples/backtest_real/market --time-policy publication_proxy --start 2023-01-01 --end 2025-12-31 --horizon 20 --output output/面试回测

# 执行完整自动测试与源码检查。
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check src tests scripts
```

想整套重新生成本文件夹里的样例，可在新目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/prepare_submission.py --output output/题目示例复算
```

该脚本调用正式流水线、查询、核对和回测，全部离线；已有示例不覆盖。财务示例的`manifest.json`校验原封存文件，外层`文件清单.json`校验此次生成的展示文件。展示导出目录本身不含SQLite；查询使用上面生成的工作区。

## 完整Windows ZIP验收

在解压根目录PowerShell执行：

```powershell
.\windows\finpipe\finpipe.exe demo --workspace output/面试验收
.\windows\finpipe\finpipe.exe query --workspace output/面试验收 --company 600519.SH --period 2025Q4
.\windows\finpipe\finpipe.exe health --workspace output/面试验收
.\windows\finpipe\finpipe.exe doctor --workspace output/面试验收
.\windows\finpipe\finpipe.exe backtest --demo --output output/人工回测验收
```

人工回测与公开样例研究的身份不同。交付ZIP还须实际解压，检查CRC与逐文件SHA，确认起始页/README链接可达，并在中文空格目录、移除Python PATH和不可用代理条件下执行离线入口。实际包验证记录随ZIP提供，不能仅用构建目录的测试代替。

## 验证范围与限制

- 正式数据来自可核验的真实归档，离线重放验证处理链路，不冒充本次重新向网站发出请求。
- 独立PDF核对仅覆盖声明的33个可比参考项；同源勾稽不是独立来源核验，未覆盖项另列。
- 公开回测是固定股票池与公告近似研究；完整历史修订、可成交约束和现金分红单独核验未完成。
- 本机无Python PATH及不可用代理验证不等同于独立干净Windows VM或操作系统断网。
- Python3.11、真实生产调度注册、外部通知、整机断电和大规模生产性能未计入验收结论。
